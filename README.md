# Abhay Khandelwal - QA Engineer Portfolio

Professional portfolio website showcasing Quality Assurance experience in POS systems, mobile (Android & iOS), API testing, and web applications.

## 🚀 Overview
- **Role:** QA Engineer
- **Specializations:** Manual Testing, Mobile Testing (iOS & Android), POS Systems, API Testing (Postman), Regression & Test Case Design, Defect Lifecycle (Jira)

## 🛠️ Built With
- Semantic HTML5 with complete SEO & OpenGraph meta tags
- Responsive CSS3 design (Custom styling, modern CSS variables, light & dark theme support)
- Vanilla JavaScript for smooth interactions, project filters, and modals

## 💻 Local Development
To run this project locally:
```bash
# Using live-server with auto-reload
npx live-server --port=5500

# Or using Python's built-in HTTP server
python -m http.server 5500
```
